IMAP server settings for common providers

MailMover connects over IMAP with SSL on port 993. Use these server names, and the full email address as the username.

ProviderIMAP serverPortPassword to use
Gmail and Google Workspaceimap.gmail.com993 (SSL)App password
Outlook.com and Hotmailoutlook.office365.com993 (SSL)App password
Yahoo Mailimap.mail.yahoo.com993 (SSL)App password
iCloud Mailimap.mail.me.com993 (SSL)App-specific password

Any other provider

Look for the incoming mail server in your provider's email settings, often under Manual settings or Client configuration. If your site is hosted with a web host, the server name and mailbox password are in the host's email settings. Choose Custom IMAP in MailMover and enter them.

Business Microsoft 365 mailboxes usually need a company sign-in rather than a password, so they cannot be moved with a password for now. See Microsoft 365 and Outlook.com.
