Transfer or Move: which should you choose?

MailMover can copy your mail and keep the original, or copy it and remove it from the old mailbox.

What is the difference between Transfer and Move?

Transfer copies your mail to the new mailbox and leaves the original where it is. Move copies it, then removes it from the old mailbox.

Which should I choose?

Choose Transfer if you are not sure. You can always delete the old mail later, but you cannot get it back once Move has removed it.

Can I see what will happen first?

Yes. A dry run lists what would be copied and changes nothing in either mailbox.

Does Transfer create duplicates if I run it twice?

No. Messages that are already in the new mailbox are skipped, so running Transfer again only copies what is missing.

When should I use Move?

Use Move when the old mailbox is near its size limit, or when you want the old mailbox empty once everything has been copied. Do a dry run and keep a backup first.
