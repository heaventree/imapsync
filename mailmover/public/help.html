Signing in to your mailbox

Some providers will not accept your normal password from another service. This page shows what to use instead, and where to get it. MailMover never stores what you type.

Jump to: Gmail and Google Workspace · Microsoft 365 and Outlook.com · Any other provider · If sign-in fails

Gmail and Google Workspace

Google does not accept your normal password here. You need an app password: a 16-character code that lets one service into your mailbox. You can delete it at any time.

  1. Sign in to your Google account and turn on 2-Step Verification if it is not on yet: myaccount.google.com/security.
  2. Open myaccount.google.com/apppasswords, type MailMover as the name and choose Create.
  3. Copy the 16-character code. Google shows it only once.
  4. In MailMover choose Gmail / Workspace (server imap.gmail.com), enter the full email address, and paste the code as the password. You can paste it with or without spaces.

Google's own guide: Sign in with app passwords.

Google Workspace (a work or school address)

  • If the app password page says the option is not available, your administrator has not allowed it. Ask them to turn on 2-Step Verification for your account and to allow app passwords.
  • IMAP access must also be on for your account. In Gmail, open Settings, then Forwarding and POP/IMAP, and make sure IMAP is enabled.

Microsoft 365 and Outlook.com

Microsoft has switched off password sign-in for IMAP on most mailboxes. If you try one, MailMover reports that basic authentication is disabled.

  • Outlook.com and Hotmail (personal): turn on two-step verification in your Microsoft account security settings, create an app password there, and use it in place of your normal password. Microsoft explains how: Manage app passwords.
  • Microsoft 365 for business or school: a password usually does not work, and an app password is normally not offered. These mailboxes need a Microsoft sign-in approved by your IT administrator. MailMover's Microsoft 365 sign-in is not switched on yet, so business Microsoft 365 mailboxes cannot be moved with a password for now.

Server name for both: outlook.office365.com.

Any other provider

Choose Custom IMAP and enter the server name your provider gives for incoming mail, usually written like imap.yourprovider.com. MailMover connects on port 993 with SSL.

  • Use the full email address as the username unless your provider says otherwise.
  • Many providers (Yahoo, iCloud, Zoho and others) also require an app password. Look for app password or third-party app in your account's security settings.
  • If your site is hosted with a web host, the server name and a mailbox password are in the host's email settings, often listed as Manual settings or Client configuration.

If sign-in fails

  • Check the server name first, then the full email address.
  • Use Test Both Logins before you start. It checks both mailboxes without moving anything.
  • Source login failed means the first mailbox rejected the details. Destination login failed means the second one did.
  • Copy the app password again. A stray space or a missing character is the most common cause.
